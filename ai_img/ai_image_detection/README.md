# AI Image Detection Forensic Module (`ai_image_detection`)
### PS-05: Digital Evidence Authenticity and Integrity Verification Platform

This module implements the **Universal Fake Detect (UnivFD)** methodology to assess whether an image is camera-captured (authentic) or synthetically generated by AI (diffusion, GAN, autoregressive, etc.).

It runs **100% locally** (zero cloud APIs or runtime downloads) adhering strictly to law enforcement and forensic lab chain-of-custody requirements.

---

## 1. Quick Start: One-Click Windows Launcher

To set up and run the platform automatically with zero manual configuration:

1. **Double-click `run_platform.bat`** in the project root folder.
   - **First run**: Automatically locates Python (3.10+), creates `.venv`, installs PyTorch and dependencies, verifies/downloads the real frozen CLIP ViT-L/14 (~890 MB) and UnivFD linear probe weights (~4 KB), detects a free port, and opens your default browser to `http://127.0.0.1:8000/`. (Takes ~3–5 minutes).
   - **Subsequent runs**: Bypasses setup and starts in seconds.
2. **To stop the server**: Double-click `stop_platform.bat` or press `CTRL+C` in the launcher console.

## 3. Core Architecture & Pipeline Stages

The core logic resides exclusively in `analyzer.py` and exposes exactly one entry point:
```python
def analyze(file_path: str, options: dict | None = None) -> dict
```
It returns the **Standard Result Format (JSON)** and never raises exceptions.

### Pipeline Stages
1. **Ingest (`ingest_image`)**: Opens with Pillow, executes `ImageOps.exif_transpose`, converts to RGB, records file size, dimensions, and estimates JPEG quality from quantization tables (DQT).
2. **Pre-process (`generate_crops`)**: CenterCrop 224x224 with **no resizing** (preserving high-frequency generative noise). Samples up to 9 crops in a 3x3 spatial grid. Pads and flags images smaller than 224px.
3. **Feature Extraction**: Encodes each crop using frozen CLIP ViT-L/14 (768-d vector).
4. **Classification**: Linear probe (`torch.nn.Linear(768, 1)`) + Sigmoid generates raw crop probabilities.
5. **Calibration (`apply_platt_scaling`)**: Applies fitted Platt scaling $P = \sigma(a \cdot \text{logit} + b)$ from `configs/calibration.yaml`.
6. **Photo-Type Heuristics (`detect_photo_type`)**: Classifies evidence as `camera_photo`, `social_media_reupload`, `screenshot`, `edited`, `small_or_blurry`, or `ai_render`.
7. **Decision Logic (`decide.py`)**: Evaluates calibrated probability against photo-type thresholds in `configs/thresholds.yaml`. Maps to:
   - `authentic` (Real)
   - `likely_tampered` (Likely fake)
   - `suspicious` (Upper half of uncertain band)
   - `inconclusive` (Lower half of uncertain band or `small_or_blurry`)
8. **Provenance Hook (`check_provenance_markers`)**: Scans EXIF, XMP, PNG text chunks, and raw byte patterns for C2PA markers and known generator strings (Midjourney, DALL-E, Stable Diffusion, Firefly, Flux). Overrides classifier if confirmed AI provenance exists.
9. **Visual Artifacts (`render_crop_heatmap`)**: Generates an overlaid 3x3 crop heatmap saved to `./artifacts/ai_image_detection/`.
10. **Caching**: Results cached by `sha256 + config_hash` in `cache/` for instant re-analysis.

## 4. API Endpoints

All endpoints are prefixed with `/api/ai_image_detection`:

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `POST` | `/api/ai_image_detection/analyze` | Multipart image upload. Returns Standard Forensic Result JSON. |
| `GET` | `/api/ai_image_detection/health` | Health check returning `{"status":"ok", "module":"ai_image_detection"}`. |
| `GET` | `/api/ai_image_detection/artifacts/{filename}` | Serves generated visual heatmap plots. |
