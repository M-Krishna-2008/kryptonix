# Package Contents: PS-05 AI CCTV Detection Runtime Transfer Package

**Package Name**: `ai_cctv_detection_runtime_<YYYYMMDD>.zip`  
**Module**: `ai_cctv_detection` (Digital Forensics Video Authenticity & Tamper Detection)  
**Target Platform**: Windows 10 / Windows 11 (64-bit x64)  

---

## 1. What is Included in this Package (Tier D: Runtime Assets)

This package contains everything needed to deploy, test, run, and retrain the forensic module on any clean Windows machine:

1. **Core Forensic Package (`ai_cctv_detection/`)**:
   - `analyzer.py`: Forensic pipeline (frame extraction, quality gates, native 224x224 tile analysis, YOLO forward pass, Platt probability calibration, artifact generation).
   - `router.py`: FastAPI router implementing the PS-05 contract (`/analyze`, `/health`, `/progress`, `/artifacts`).
   - `schemas.py`: Pydantic V2 schemas matching the non-negotiable PS-05 result format.
   - `static/`: Plain vanilla HTML5, CSS3, and ES6 JavaScript user interface (no build step, no npm).
   - `configs/`: Platt calibration coefficients (`calibration.yaml`), quality thresholds (`quality.yaml`), and decision rules (`thresholds.yaml`).
   - `models/best.pt`: The fine-tuned forensic CCTV classifier model weights (11.0 MB).
2. **Standalone Runner & Launchers**:
   - `main_standalone.py`: Standalone FastAPI app mounting the module router and serving the web interface.
   - `run_platform.bat`: Idempotent launcher with hardware auto-detection, winget prerequisite installation, virtual environment setup, dynamic port allocation, and browser launch.
   - `stop_platform.bat`: Single double-click graceful shutdown script.
   - `check_system.bat` & `check_system.ps1`: Diagnostic tool verifying system readiness.
   - `clean_project.bat`: Safe cache cleanup script with default dry-run mode.
   - `archive_training_data.bat` & `restore_training_data.bat`: Archival and restoration scripts for retraining datasets.
3. **Model Weights (`models/`)**:
   - `models/best.pt`: Active forensic detector weights (11.0 MB).
   - `models/yolo11s-cls.pt`: YOLO11s classification base checkpoint (13.6 MB).
4. **Tooling & Test Suite**:
   - `tools/`: Retraining and dataset building scripts (`build_dataset.py`, `train.py`, `calibrate.py`, `metadata_check.py`).
   - `tests/`: Automated unit/integration tests (`test_analyzer.py`) and 4 sample test clips (`api_test_clip.mp4`, `sample_1_cctv.mp4`, `sample_2_blurry.mp4`, `sample_3_tampered.mp4`).
5. **Contract Specifications & Lockfiles**:
   - `requirements-lock.txt`: Fully pinned list of all 67 dependencies with exact versions (`==x.y.z`).
   - `MODULE_MANIFEST.json`: Machine-readable metadata for platform integration.
   - `ENVIRONMENT.md`, `PORTABILITY_REPORT.md`, `SETUP_ON_NEW_LAPTOP.md`, `README.md`.
   - `MANIFEST_SHA256.txt`: Bit-level cryptographic checksum of every file in the package.
   - `verify_package.bat`: Double-click package verification script.

## 3. What Happens on the Destination Machine

When this transfer package is copied to a new Windows laptop:

1. **Pre-Flight Verification**:
   - Run `verify_package.bat` to confirm all file checksums match `MANIFEST_SHA256.txt`.
2. **First-Run Provisioning (`run_platform.bat`)**:
   - If Python 3.10 is missing, the launcher installs it automatically via `winget` (~30 MB).
   - If Visual C++ 2015-2022 Redistributable is missing, the launcher installs it via `winget` (~25 MB).
   - The launcher initializes an isolated virtual environment (`.venv`).
   - It downloads locked binary wheels from PyPI and PyTorch:
     - On NVIDIA GPU machines: PyTorch CUDA (`torch==2.6.0+cu124` ~1.8 GB).
     - On Intel/AMD CPU machines: PyTorch CPU (`torch==2.6.0+cpu` ~200 MB).
     - Standard dependencies: Ultralytics, PyAV, OpenCV, Scikit-Learn (~150 MB).
   - Total first-run download: **~400 MB (CPU laptop)** or **~2.0 GB (GPU laptop)**.
   - Once installed, the hash of `requirements-lock.txt` is cached to `.venv/.installed-hash`.
3. **Subsequent Runs**:
   - Subsequent executions skip all checks and start the platform in **< 3 seconds** fully offline with **0 MB downloads**.
